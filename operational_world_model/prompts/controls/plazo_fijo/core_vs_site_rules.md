# Core vs Site Rules

For PF, Core vs Site is unidirectional.
Analyze records from Core toward Site/interface.
Do not generate inverse Site to Core analysis unless explicitly requested and supported.

Typical date field from the SQL Skill rules:
- CORE_CREATED_AT_DATETIME

Useful for inconsistencies, differences, orphan records, missing records, alerts, or reconciliation failures between core and site/interface.
