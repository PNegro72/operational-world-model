# Cuenta Puente Rules

For balance questions use `NET_WSL_DAY`.
Do not use `ABS_WSL_DAY` as balance.
Do not use `HFSPD_AMT` as balance.

Meanings:
- `ABS_WSL_DAY` represents gross volume.
- `HFSPD_AMT` represents line detail.

For contract questions use `EXT_CONTRACT`.
Default filters and special rules must come from registry.
